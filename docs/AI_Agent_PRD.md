## 二、产品概述

### 2.1 需求背景

小红书运营面临的核心痛点：**内容生产耗时、热点捕捉滞后、合规风险高、数据复盘碎片化**。传统运营依赖人工完成选题策划、文案撰写、封面设计、合规校验、发布排期和数据分析全流程，单条种草视频制作耗时约2小时，效率低且难以规模化。

随着大模型和Agent技术的发展，小红书运营已出现自动化实践案例——有Agent系统仅用14天即在小红书吸粉5000人并获得商业收入。本平台旨在将“策-采-编-发-复盘”全链路Agent化，将运营效率从“2小时/条”提升至“分钟级自动产出”。

### 2.2 产品目标

| 目标维度     | 具体指标                              |
| ------------ | ------------------------------------- |
| 内容生产效率 | 单条笔记从策划到产出≤10分钟           |
| 发布频次     | 支持日均10-30条内容的自动化生产与发布 |
| 合规通过率   | 发布前合规拦截率100%，违规内容零发布  |
| 运营人效     | 单人可管理账号数从3-5个提升至20+个    |
| 内容质量     | 生成内容去AI味，保持账号风格一致性    |

### 2.3 产品定位

**面向小红书内容运营团队的AI Agent智能生产力平台**，提供从热点洞察、内容创作、合规审校、智能发布到数据复盘的端到端自动化运营能力。

## 四、功能需求

### 4.1 模块一：策划工作台（热点洞察Agent）

#### 4.1.1 功能列表

| 功能ID | 功能名称 | 优先级 | 简要描述                                 |
| ------ | -------- | ------ | ---------------------------------------- |
| P-01   | 热点榜单 | P0     | 24小时实时展示小红书全站热点话题与上升词 |
| P-02   | 爆款拆解 | P0     | 自动分析低粉高数据笔记的爆款结构         |
| P-03   | 选题推荐 | P0     | 基于账号定位与热点生成可落地的选题列表   |
| P-04   | 竞品监控 | P1     | 监控竞品账号内容动态与数据变化           |
| P-05   | 趋势预测 | P2     | 基于历史数据预测未来3-7天内容趋势        |

#### 4.1.2 详细需求

**P-01 热点榜单**

| 项目     | 描述                                                                      |
| -------- | ------------------------------------------------------------------------- |
| 触发条件 | 系统定时任务（每30分钟）自动执行 / 用户手动刷新                           |
| 用户操作 | 查看热点列表、按分类筛选（美妆/穿搭/美食/旅行/家居/知识等）、查看热度趋势 |
| 系统响应 | 展示热度分、上升速度、相关笔记数、核心关键词                              |
| 输出结果 | 热点榜单列表（含热度值、趋势箭头、关联话题标签）                          |

**数据规则**：

- 热度分 = 搜索量×0.3 + 笔记增量×0.3 + 互动增量×0.4
- 榜单保留TOP50，每30分钟更新一次

**P-02 爆款拆解**

| 项目     | 描述                                                                                              |
| -------- | ------------------------------------------------------------------------------------------------- |
| 触发条件 | 用户输入目标关键词/类目 / 系统自动推送                                                            |
| 用户操作 | 选择分析范围（近7天/近30天）、查看拆解报告                                                        |
| 系统响应 | Agent自动爬取低粉（<5000粉）高互动（赞藏评>1000）笔记，拆解标题结构、封面元素、正文框架、互动引导 |
| 输出结果 | 结构化爆款拆解报告（含可复用的标题模板、封面构图、文案结构）                                      |

**P-03 选题推荐**

| 项目     | 描述                                                                                   |
| -------- | -------------------------------------------------------------------------------------- |
| 触发条件 | 用户进入策划工作台 / 点击“生成选题”                                                    |
| 用户操作 | 配置选题数量（5/10/20条）、选择内容方向                                                |
| 系统响应 | Agent结合热点榜单+账号知识库+爆款结构，生成选题列表                                    |
| 输出结果 | 选题卡片列表（含标题建议、内容方向、预估热度、关联话题标签），支持一键加入内容生产队列 |

### 4.2 模块二：创作工作台（内容创作Agent）

#### 4.2.1 功能列表

| 功能ID | 功能名称     | 优先级 | 简要描述                                  |
| ------ | ------------ | ------ | ----------------------------------------- |
| C-01   | 文案生成     | P0     | 基于选题一键生成标题、正文、话题标签、CTA |
| C-02   | 去AI味改写   | P0     | 对生成文案进行自然化改写，去除AI痕迹      |
| C-03   | 封面图生成   | P0     | 自动生成3:4比例的小红书风格封面图         |
| C-04   | 配图生成     | P1     | 生成16:9正文配图                          |
| C-05   | 视频脚本生成 | P1     | 基于文案自动生成短视频脚本                |
| C-06   | 多格式输出   | P1     | 支持图文笔记、短视频脚本等多种内容形式    |
| C-07   | 风格模仿     | P0     | 通过Few-shot学习模仿账号历史内容风格      |

#### 4.2.2 详细需求

**C-01 文案生成**

| 项目     | 描述                                                                                                |
| -------- | --------------------------------------------------------------------------------------------------- |
| 触发条件 | 用户从选题列表中选择一个选题 / 手动输入商品名+卖点                                                  |
| 用户操作 | 输入/确认选题方向、选择文案风格（种草型/干货型/测评型）、点击“生成”                                 |
| 系统响应 | Agent调用大模型生成：标题（3-5个备选）、正文（300-800字）、话题标签（5-10个）、CTA（行动引导1-2条） |
| 输出结果 | 完整文案包，支持编辑、重新生成、保存                                                                |

**输入参数**：

- 必填：选题/商品名称、核心卖点（1-3个）
- 选填：目标人群、内容风格、字数要求、参考笔记链接

**C-02 去AI味改写**

| 项目     | 描述                                                          |
| -------- | ------------------------------------------------------------- |
| 触发条件 | 文案生成后自动触发 / 用户手动点击“去AI味”                     |
| 用户操作 | 选择改写强度（轻度/中度/深度）、点击执行                      |
| 系统响应 | Agent对文案进行口语化改写，增加语气词、个人化表达、真实感细节 |
| 输出结果 | 改写后文案（展示改写前后对比）                                |

**改写规则**：

- 删除模板化开头（如“今天给大家分享一下”）
- 增加第一人称真实体验描述
- 加入口语化表达和情绪词
- 避免“首先/其次/最后”等结构化连接词

**C-03 封面图生成**

| 项目     | 描述                                                                   |
| -------- | ---------------------------------------------------------------------- |
| 触发条件 | 文案生成后 / 用户单独进入封面设计                                      |
| 用户操作 | 选择封面模板、上传素材图/输入图片描述、点击生成                        |
| 系统响应 | Agent调用图像生成模型，按3:4比例生成封面图，自动添加标题文字和视觉元素 |
| 输出结果 | 封面图（3-5个备选），支持下载、编辑                                    |

**封面模板库**：

- 对比型（前后对比图+大字标题）
- 清单型（数字列表+产品图）
- 人物型（博主照片+文案叠加）
- 纯文型（大字标题+简约背景）

**C-07 风格模仿**

| 项目     | 描述                                                                    |
| -------- | ----------------------------------------------------------------------- |
| 触发条件 | 首次使用账号时配置 / 用户上传历史笔记                                   |
| 用户操作 | 上传5篇以上历史优质笔记作为示例                                         |
| 系统响应 | Agent分析示例笔记的语言风格、句式结构、用词偏好、情绪基调，建立风格模型 |
| 输出结果 | 后续所有生成内容自动匹配该风格                                          |

### 4.3 模块三：审校工作台（合规审校Agent）

#### 4.3.1 功能列表

| 功能ID | 功能名称     | 优先级 | 简要描述                                         |
| ------ | ------------ | ------ | ------------------------------------------------ |
| R-01   | 双重内容预审 | P0     | 对正文、标题、封面文字、图片文字进行两层预审     |
| R-02   | 合规检查     | P0     | 基于小红书社区规范进行违规内容检测               |
| R-03   | 声明验证     | P0     | 验证功效声明、数据引用是否有据可查               |
| R-04   | 原创性检查   | P0     | 检测内容与已有笔记的相似度                       |
| R-05   | 梯度修复     | P1     | 按梯度自动修复违规内容并复检                     |
| R-06   | 三道门禁     | P0     | 声明验证+原创性检查+合规检查，任一不通过自动阻断 |

#### 4.3.2 详细需求

**R-01 双重内容预审**

| 项目     | 描述                                                             |
| -------- | ---------------------------------------------------------------- |
| 触发条件 | 内容提交审校 / 发布前自动触发                                    |
| 用户操作 | 提交待审内容、查看审校报告                                       |
| 系统响应 | 第一层：基于规则库的候选命中检测；第二层：基于语义的深层违规分析 |
| 输出结果 | 审校报告（通过/警告/不通过），标注风险点和风险等级               |

**检测维度**：

- 绝对化用语（“最”“第一”“唯一”等）
- 功效宣称（医疗功效、减肥效果等）
- 虚假数据（无来源的数据引用）
- 敏感词（政治、色情、暴力等）
- 诱导行为（诱导点赞、诱导评论等）
- 版权风险（图片水印、文字抄袭等）

**R-05 梯度修复机制**

| 项目     | 描述                                                                                                             |
| -------- | ---------------------------------------------------------------------------------------------------------------- |
| 触发条件 | 审校不通过                                                                                                       |
| 用户操作 | 选择“自动修复”或手动修改                                                                                         |
| 系统响应 | 按以下梯度自动修复：披露（添加免责声明）→ 证据（补充数据来源）→ 收窄断言（弱化绝对化表述）→ 最小改写 → 删除/暂缓 |
| 输出结果 | 修复后内容，自动进入复检流程                                                                                     |

**R-06 三道门禁**

三道门禁在发布前串行执行：

| 门禁               | 检查内容                             | 不通过处理     |
| ------------------ | ------------------------------------ | -------------- |
| 第一道：声明验证   | 验证功效声明、数据引用是否有可靠来源 | 标记待补充来源 |
| 第二道：原创性检查 | 与已有笔记库比对相似度（阈值<30%）   | 标记需修改     |
| 第三道：合规检查   | 基于社区规范全量扫描                 | 自动修复或阻断 |

#### 4.4.2 详细需求

**D-01 智能排期**

| 项目     | 描述                                                                              |
| -------- | --------------------------------------------------------------------------------- |

| 输出结果 | 发布日历视图，标注推荐发布时间                                                    |

**排期规则**：

- 优先匹配账号历史互动高峰时段
- 同账号每日发布不超过3条
- 同类目内容间隔不少于2小时
- 支持设定“库存缓冲”（保留3-5条已审内容备用）

**D-02 一键发布**

| 项目     | 描述                                                 |

| 系统响应 | 通过API或MCP协议调用小红书发布接口，自动完成内容发布 |
| 输出结果 | 发布成功/失败状态回传，发布后链接                    |

**发布流程**：

```
扫码登录 → 草稿预览 → 显式批准（人工确认） → 自动发布 → 状态回传
```

| 系统响应 | Agent识别评论意图（询问/好评/差评/广告），匹配知识库进行自动回复 |
| 输出结果 | 自动回复内容，高频未解决问题转入知识库补充队列                   |
